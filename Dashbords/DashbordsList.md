# Дашборды
Здесь содержится информация о созданных дашбордах, направленных на решение различных бизнес задач. Дашборды созданы в DataLens и включают в себя различные чарты (в том числе и визуализацию геоданных), фильтры и условное форматирование.

## 1. Дашборд для агентства недвижимости
[Ссылка на дашборд](https://datalens.yandex/noepccl4zcyo8?_embedded=1&_no_controls=1&_theme=light&tab=aW)

### Цель дашборда
Дашборд создан на основе проведённого анализа рынка недвижимости Санкт-Петербурга и Ленинградской области. 
Его основная задача — предоставить инструмент для мониторинга рыночной ситуации: отслеживание ценовой динамики, оценка ликвидности объектов (скорость продаж), анализ структуры предложения и выявление наиболее перспективных (или проблемных) локаций для инвестиций и продаж.

### Источник данных
База данных PostgreSQL

### Ключевые метрики (Индикаторы)
- Уникальное число квартир
- Среднее число комнат
- Средняя площадь
- Средняя площадь кухни
- Средняя жилая площадь

### Основные визуализации
1) Линейные графики (тренды) — отображают динамику во времени: изменение количества квартир, средней цены и среднее количество дней продажи на одну квартиру
2) Горизонтальные барчарты (Топ-5 населённых пунктов): по количеству квартир, по средней цене, по количеству дней продажи
3) Таблица "Средняя стоимость 1 кв. метра" — ранжирует населенные пункты по цене "квадрата"
4) Столбчатые диаграммы (факторный анализ): влияние планировки, типа жилья, парковки и водоёмов на стоймость квадратного метра
5) Графики сезонности — анализ размещения объявлений по дням недели и месяцам/годам

### Фильтры и интерактивность
На дашборде предусмотрена гибкая система фильтров для детализации данных (расположена сверху):

- Дата объявления — выбор временного периода.
- Апартаменты (Да/Нет) — отсев жилого фонда.
- Открытая планировка (Да/Нет) — фильтр по типу планировки.
- Название населенного пункта — возможность выбрать конкретный город.
- Тип населенного пункта (город/поселок и т.д.).
- Гранулярность — уровень детализации данных (день/неделя/месяц/год).

### Бизнес‑эффект дашборда
- оптимизация ценообразования;
- стратегическое планирование рекламных компаний и вывода новых объектов на рынок;
- Приоритизация локаций (для повышения маржинальности).

## 2. Расчёт метрик сервиса доставки еды
[Ссылка на дашборд](https://datalens.yandex/tbeqq6og8stse?_embedded=1&_no_controls=1&_theme=light)

### Цель дашборда
Дашборд предназначен для комплексной оценки эффективности работы сервиса доставки готовой еды путём расчёта основных бизнес-метрик. 
Он объединяет три ключевых направления:
- Финансовая эффективность (средний чек, LTV блюд)
- Удержание пользователей (Retention Rate)
- Конверсия (Conversion Rate)
На отдельной вкладке подготовлен аналитический отчёт по данным, а также сформулированы рекомендации для сервиса доставки еды.

### Источник данных
База данных PostgreSQL. Информация представлена за 2 месяца (май-июнь 2021 г.) по г. Саранску.

### Визуализация метрик
На дашборде метрики отражены в следующих графиках
1) Линейные графики (DAU и Conversion Rate по дням) - для изучения динамики
2) Столбчатые диаграммы (Средний чек, LTV ресторанов, Retention Rate) - для сравнения показателей
3) Таблицы (LTV блюд и Retention Rate по месяцам) - для детального изучения 

### Бизнес‑эффект дашборда
- оценка эффективности маркетинга;
- управление средним чеком;
- оптимизация рекомендательных алгоритмов при подборке блюд и ресторанов.

## 3. Дашборд для страховой компании
[Ссылка на дашборд](https://datalens.yandex/kd1cr0lfk9h04?_embedded=1&_no_controls=1&_theme=light)

### Цель дашборда
Дашборд создан для глубокого анализа клиентской базы страховой компании. Основная задача — изучить профиль клиентов, выявить факторы, влияющие на размер страхового взноса (возраст, пол, ИМТ, курение, наличие детей, район проживания).

### Источник данных
База данных PostgreSQL.

### Ключевые метрики
На верхней панели выведены основные агрегаты по всей базе:
- Общее количество клиентов.
- Средний возраст клиентов.
- Средний страховой взнос.

### Визуализация метрик
Дашборд использует разнообразные графические форматы для наглядного сравнения групп:

**Круговые диаграммы (donut):**
- Распределение доходов по районам
- Соотношение клиентов по полу
- Соотношение курящих/некурящих

**Столбчатые горизонтальные диаграммы:**
- Распределение среднего страхового взноса по категориям 
- Распределение среднего взноса (в разрезе пола и ИМТ)
- Распределение среднего взноса (в разрезе пола и количества детей)
- Распределение среднего взноса (в разрезе курящих и ИМТ)
- Распределение среднего взноса (в разрезе курящих по районам)

**Визуализация статистических показателей:**
- Количество клиентов по категориям (столбчатая вертикальная диаграмма)
- Таблица корреляции страхового взноса от категории клиентов

### Фильтры и интерактивность
Для графиков Распределение среднего страхового взноса по категориям и Количество клиентов по категориям предусмотрены отдельные фильтры по категориям: возраст, пол, ИМТ, курение, наличие детей, район проживания.

### Бизнес-эффект дашборда
1) Персонализированное ценообразование в зависимости от категории клиентов
2) Маркетинговая оптимизация под отдельные категории клиентов
3) Улучшение клиентского опыта
